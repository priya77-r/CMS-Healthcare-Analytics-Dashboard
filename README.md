CMS Healthcare Analytics Dashboard

An interactive Power BI dashboard that analyzes US healthcare provider data to show how hospitals are distributed across states, who owns them, and which ones offer emergency services.

Project Overview

Healthcare provider data is large and hard to read in raw form. This project turns it into a dashboard where anyone can filter, compare and explore providers by state, ownership type and emergency service availability.

Questions Explored
How are hospitals distributed across US states?
How does hospital ownership vary across states?
Which hospitals offer emergency services, and where are they located?
How do state-wise healthcare metrics compare?
Tools Used
Power BI for the dashboard and interactive visuals
DAX (Data Analysis Expressions) for measures and calculations
Dashboard Features
Custom DAX measures for key healthcare metrics
Interactive visuals and filters to compare providers by state, ownership and emergency services
A single dashboard view that makes state-wise healthcare trends easy to read at a glance
